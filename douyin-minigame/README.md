# 叠叠高 —— 抖音小游戏上线全流程（新手版）

> 目标：用一个最简单的小游戏，**完整跑通一次「开发 → 测试 → 资质 → 提审 → 上线」**。
> 游戏本身已经写好（`game.js`），你不需要写代码，只需要按顺序照做。

---

## 先看全局：真正卡时间的是资质，不是代码

| 阶段 | 内容 | 预计耗时 | 是否卡工期 |
|---|---|---|---|
| A. 资质（今天就开始） | 软件著作权、小游戏备案 | **几周到两个月** | ⚠️ 关键路径 |
| B. 环境 | 装开发者工具、创建小游戏拿 AppID | 半天 | 否 |
| C. 跑通游戏 | 导入代码、模拟器试玩、手机真机预览 | 半天 | 否 |
| D. 上线材料 | 名称、图标、简介、截图、类目 | 半天 | 否 |
| E. 提审发布 | 上传代码 → 提交审核 → 发布 | 审核约 1~3 个工作日 | 否 |

**结论：B~D 一两天就能做完，然后就是等资质。所以第 A 步要和 B 步同一天启动、并行推进。**

> 各项资质要求、耗时、尺寸以抖音开发者平台后台**当时的提示为准**，平台规则会调整，下文数字只作估算。

---

## 第 0 步：先拍板两件事（5 分钟，但很重要）

1. **用什么主体发布？**
   - 公司主体（乐谱兰斯）：资质最完整、后续可做变现。但它挂公司名义，**建议先跟领导报备**：这是流程练习项目，会占用公司主体的一个小游戏名额和备案记录。
   - 个人主体：不用走公司流程，但可用能力有限制，部分类目/变现不可用。
   - 你注册开发者账号时如果已经选了主体，就沿用它。
2. **游戏叫什么名字？**
   - 「叠叠高」这类通用名大概率已被占用。建议起一个有辨识度的名字，比如「立谱叠叠乐」，先在后台创建时试一下能不能用。
   - **软著名称、小游戏名称要保持一致**（审核时会核对），名字定了再申请软著。

---

## 第 A 步：资质（今天启动，并行推进）

### A1. 软件著作权（软著）
抖音小游戏提审一般要求提供软著证书（不含内购的游戏），带付费内购的游戏还需要版号——本项目**不做内购**，避开版号。

- 办理途径：中国版权保护中心官网自己申请（免费，但慢，通常一到两个月），或委托代理机构加急（收费，周期短）。
- 材料：申请表 + 部分源代码（就用本目录 `game.js`）+ 操作说明文档（截几张游戏截图加文字说明即可）。
- 用公司主体申请时，著作权人填公司。

### A2. 小游戏备案
按工信部要求，小程序/小游戏上线前需要完成备案，在**抖音开发者平台后台**里直接发起，按提示填主体信息、负责人信息，期间会收到管局短信核验，**要及时回复**。周期一般一到几周。

### A3. 游戏自审自查报告等材料
后台提审时会提示需要上传的材料（例如自审自查报告模板），按模板填写即可。

---

## 第 B 步：准备环境

### B1. 下载抖音开发者工具
1. 打开抖音开放平台文档中心（developer.open-douyin.com），找到「开发者工具」下载页。
2. 选你电脑系统（Windows / Mac）对应版本，下载安装。
3. 打开后用**抖音 App 扫码登录**（用注册开发者平台的那个抖音账号）。

### B2. 在后台创建小游戏，拿到 AppID
1. 登录抖音开发者平台 → 「创建应用」→ 选择 **小游戏**。
2. 填名字（第 0 步定好的）→ 创建。
3. 进入这个小游戏的管理后台 → 「开发」或「开发设置」→ 复制 **AppID**（一般是 `tt` 开头的一串字符）。

---

## 第 C 步：把游戏跑起来

### C1. 下载游戏代码
1. 打开 GitHub 仓库页面，切到分支 `claude/douyin-minigame-launch-5zl4rc`。
2. 点绿色按钮 **Code → Download ZIP**，解压。
3. 找到里面的 `douyin-minigame` 文件夹，复制到一个**路径里没有中文和空格**的位置，比如 `D:\games\douyin-minigame`。

文件夹里只有 4 个文件：

| 文件 | 作用 | 你要动吗 |
|---|---|---|
| `game.js` | 游戏全部逻辑 | 不用动 |
| `game.json` | 配置（竖屏） | 不用动 |
| `project.config.json` | 项目配置 | **要填 AppID** |
| `README.md` | 本说明 | — |

### C2. 填 AppID
用记事本打开 `project.config.json`，把 `在这里填你的AppID` 换成 B2 复制的 AppID，保存。

### C3. 导入项目
1. 打开抖音开发者工具 → 「导入项目」（或「打开项目」）。
2. 目录选 `douyin-minigame` 文件夹，类型选 **小游戏**，AppID 填你的。
3. 如果工具提示配置文件格式不对、要帮你重建，选同意即可——`game.js` 不会被覆盖。

### C4. 模拟器试玩
导入后左侧模拟器会直接运行：
- 首页显示「叠叠高」→ 点一下开始；
- 方块左右移动，点屏幕放下，没对齐的部分会被切掉掉下去；
- 对得很准会出现「完美!」并且方块不变窄；
- 切没了游戏结束，可以「再来一局」或「炫耀给好友」。

### C5. 手机真机预览（必做）
1. 工具顶部点 **预览**，出现二维码。
2. 用抖音 App 扫码，在手机上玩一遍，重点看：文字有没有被刘海挡住、点击是否灵敏、分享能否拉起。
3. 有问题把截图发给我，我来改。

---

## 第 D 步：准备上线材料（后台 → 基本信息）

| 项目 | 建议填法 |
|---|---|
| 名称 | 第 0 步定的名字（与软著一致） |
| 图标 | 一张方形图，按后台提示尺寸；可直接截游戏里的方块塔做 |
| 简介 | 「点一下放方块，对得越准叠得越高。一局一分钟，看看你能叠几层。」 |
| 类目 | 休闲益智（以后台可选项为准） |
| 截图 | 用 C5 手机预览时截 3 张：首页、游戏中、结算页 |

---

## 第 E 步：上传、提审、发布

1. 开发者工具顶部点 **上传**，版本号填 `1.0.0`，备注填「首个版本」。
2. 回到开发者平台后台 → 「版本管理」，能看到刚上传的版本。
3. 确认资质（软著、备案）已经完成并上传 → 点 **提交审核**。
4. 审核通过后，在后台点 **发布**。发布后在抖音里搜游戏名就能找到。

**审核常见被拒原因（提前规避）：**
- 名称和软著不一致 / 资质材料缺失；
- 截图、简介与实际玩法不符；
- 素材侵权：照搬别人爆款的名字、美术、音乐会被拒。本游戏所有画面都是代码画的纯色方块，不存在这个问题。

## 关于「参考爆款」：这个游戏对照了哪几条

| 爆款共同点 | 本游戏怎么做的 |
|---|---|
| 玩法极简、只有一个动作 | 全程只有「点一下」 |
| 有可拍摄的瞬间 | 被切掉的碎块下落、连续「完美 ×N」 |
| 靠内容和社交起飞 | 结算页「炫耀给好友」，分享文案带分数 |
| 单局 1~3 分钟 | 速度逐层加快，自然在一两分钟内结束 |
| 不靠堆关卡 | 无关卡，无限叠，只比层数 |

> 这一版的定位是**跑通流程**，不是冲爆款。流程跑通后，下一轮迭代可以考虑：排行榜、音效、录屏分享、激励视频广告（变现需要主体和资质支持，届时再评估）。
